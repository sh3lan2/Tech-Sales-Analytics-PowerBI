# 📈 Tech Sales & Discount Impact Performance Dashboard

An end-to-end Power BI analytics project evaluating revenue performance, multi-channel distribution, discount margin impact, and regional sales performance across major regional markets in Egypt.

---

## 🖼️ Dashboard Preview
![Sales Impact Overview](/Screenshot%202026-09-19%20150533.png)

---

## 📊 Executive Summary & Key KPIs
- **Total Revenue:** $2.76M across all active sales channels.
- **Discount Impact:** $2.56M total discounts applied.
- **Total Volume Sold:** 4,227 units.
- **Average Order Value:** $3,195 per transaction.

---

## 🛠️ Tech Stack & Key Features
- **Business Intelligence:** Power BI Desktop (DAX measures, visual hierarchy, cross-filtering).
- **Data Transformation & Modeling:** Cleaned and structured transactional data using Power Query, handling date hierarchies and discount margin logic.
- **Multi-Channel Analysis:** Sales distribution split across **Distributor** (38.4%), **Physical Store** (31.24%), and **Online** (30.36%).
- **Regional Segmentation:** Geographical breakdown tracking revenue across **Giza** ($500K), **Cairo** ($464K), **Asyut** ($450K), **Alexandria** ($404K), **Tanta** ($372K), and **Mansoura** ($365K).
- **Product & Trend Analysis:** Category breakdown covering Laptops, Phones, Monitors, Keyboards, Headphones, and Tablets, along with a 12-month revenue trend analysis.
